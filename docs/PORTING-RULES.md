## 1. Дроби — сердце точности

**Замерено на живой Булке:** `fraction.js` 5.2.1 хранит `s` (знак, ±1) отдельно,
а `n` и `d` — **BigInt**, всегда неотрицательные и всегда сокращённые.

```
F('23/800')  → s=1  n=23n  d=800n
F('-3/4')    → s=-1 n=3n   d=4n
```

Правила:

- `n`/`d` в GDScript — `int` (64 бита). Знак хранится **отдельно** (`s`), как в
  оригинале: это не косметика, от этого зависит поведение `floor` у отрицательных.
- **Сокращать на каждой операции.** И сокращать *крест-накрест до* умножения
  (`a.n/g1 * b.d/g2`), а не после: иначе промежуточное произведение вылетает за
  64 бита там, где результат помещается свободно.
- Никакой плавающей точки в позициях событий. `float` появляется **только** на
  границе со звуком и в legacy-RNG (см. §4), где он есть и в оригинале.
- `1/2` в GDScript — **целочисленное деление**. Любое деление литералов пишется
  через `Fraction` или с явной точкой (`1.0/2.0`). Это ловушка номер один.
- `show()` печатает `s*n + "/" + d` — формат, в котором лежит эталон.

## 2. Класс Pattern: чего в GDScript нет

В JS паттерн — объект с `query`, а сотни методов навешиваются на прототип
функцией `register()` из разных файлов. В GDScript прототипов нет.

- `query` — `Callable`, принимает `State`, возвращает `Array[Hap]`. Так же, как
  в оригинале: **паттерн есть функция запроса на интервале**, а не список.
- Методы объявляются на классе `Pattern` явно. Реестр `register()`
  воспроизводится как таблица имён → `Callable`, чтобы работали
  «патернифицированные» аргументы и вызов по имени из mini-нотации.
- **Патернификация аргументов обязательна.** `register(name, func)` в оригинале
  делает так, что любой аргумент может быть паттерном:
  `fast("<1 2 3>")` работает. Правило переноса: аргументы прогоняются через
  `reify`, и если все они «чистые» (`__pure`), зовётся простая ветка; иначе —
  `appLeft` + `innerJoin` (см. `pattern.mjs:1690–1730`).
- `undefined` → `null`. Проверка `hap.whole == undefined` → `hap.whole == null`.
  Разницы между `undefined` и `null` в оригинале по смыслу нет: `whole == null`
  означает «аналоговое событие».
- Значения событий (JS-объекты) → `Dictionary`. Порядок ключей в Godot
  сохраняется, но **сравнивать словари по порядку нельзя** — только по содержимому.

## 3. Замыкания и рекурсия запросов

- Лямбды GDScript захватывают по значению. Там, где JS замыкается на
  переменную цикла, в GDScript нужно связывать явно (`bind`), иначе все
  замыкания получат последнее значение.
- Глубина рекурсии: `splitQueries` + вложенные `[[[[...]]]]` дают глубокий стек.
  Предел проверяется тестом `edge/deep-nest`.

## 4. Случайные числа — бит в бит

По умолчанию в Strudel включён режим **`legacy`** (`signal.mjs:601`,
`RNG_MODE = 'legacy'`). Переносится именно он; «precise» — вторым режимом.

Алгоритм (`signal.mjs:571–590`), все операции **32-битные знаковые**:

```
__xorwise(x):  a = (x << 13) ^ x
               b = (a >> 17) ^ a      // арифметический сдвиг
               return (b << 5) ^ b
__timeToIntSeed(x) = __xorwise( trunc( frac(x / 300) * 536870912 ) )
__intSeedToRand(x) = (x % 536870912) / 536870912
timeToRands(t, n):  seed = timeToIntSeed(t)
                    n раз: выдать intSeedToRand(seed), seed = xorwise(seed)
rand = signal(t → abs(timeToRands(t + randSeed, 1)))
```

**Замерено в браузере:** `1<<31 = -2147483648`, `(-1)>>17 = -1`,
`(-1)>>>16 = 65535`, `Math.imul(0x85ebca6b,3) = -1849467071`.
GDScript считает в 64 битах, поэтому после каждого сдвига и xor — приведение к
int32 со знаковым расширением. Отдельная функция `_i32()`, без неё
последовательность разойдётся уже на первом цикле.

Вход `t` здесь — **число с плавающей точкой** (в JS `Fraction + number` даёт
`Number`), и это не упрощение, а свойство оригинала: legacy-RNG работает по
float-времени. Переносится как есть.

`?` в mini-нотации — **не то же самое**, что `degradeBy`: она зовёт
`rand.early(0.0003 * seed)`, где `seed` — порядковый номер вопросительного знака
в строке (`mini.mjs:11`, `mini.mjs:46`). Счётчик общий на разбор и увеличивается
также для `|` и `.` (`krill.pegjs`, `choose_tail`, `dot_tail`).

Сигнал берёт значение в **начале** интервала (`signal.mjs:20`,
`func(state.span.begin, ...)`), а не в середине.

## 5. Слияние управляющих паттернов

Место, где порты расходятся чаще всего. Оригинал: `pattern.mjs:1042–1200`.

- Выравниваний восемь: `in` (по умолчанию), `out`, `mix`, `squeeze`,
  `squeezeout`, `reset`, `restart`, `poly`.
- `appLeft` — структура от левого, `appRight` — от правого, `appBoth` —
  пересечение обоих `whole`.
- `struct` = `keepif.out`, `mask` = `keepif.in` — не наоборот.
- `set`/`keep`/`add`/… строятся одной таблицей `COMPOSERS`; переносить таблицей,
  а не двадцатью функциями.
- Для не-объектных значений `_composeOp` заворачивает в `{value: x}`.

## 6. Mini-нотация

Грамматика — `mini/krill.pegjs` (PEG). Переносится **рекурсивным спуском**,
узел в узел, с сохранением семантики модификаторов:

- вес: `weight = (былое ?? 1) + (a ?? 2) - 1` — поэтому `x@3` даёт 3, а
  одинокое `_` даёт 2;
- повтор `!`: та же формула, плюс он **вытесняет** прежний `replicate` из списка
  операций и выставляет `weight = reps`;
- `?` — см. §4;
- ошибка разбора обязана нести **позицию в строке** (`mini.mjs:181`): без этого
  чужой пользователь не отладит свой код.

## 7. Что не переносится дословно

| оригинал | как в плагине | почему |
|---|---|---|
| `curry` | нет | нужен только ради JS-синтаксиса |
| `Pattern.prototype[...]` | явные методы + реестр | нет прототипов |
| `strudelScope` | реестр функций | не нужен eval-скоуп |
| `console`/`logger` | `push_error` / `push_warning` | штатный путь Godot |
| WebAudio-граф | шины и голоса Godot | другая платформа |
| загрузка сэмплов по сети | только локальные файлы | требование ТЗ |

## 8. Стиль

- Имена — `snake_case`, как принято в Godot; `queryArc` → `query_arc`,
  `degradeBy` → `degrade_by`. **В строках mini-нотации и в именах функций
  Strudel регистр сохраняется** — иначе чужой код перестанет вставляться без правок.
- Публичные методы документируются docstring'ами: всплывающая справка редактора
  — часть продукта.
- Каждый портированный файл несёт в шапке ссылку на оригинал с номерами строк.
- Сомнительное место помечается `# TODO(port): причина` и попадает в отчёт, а не
  замалчивается.

## 9. Проверка

Ничего не считается перенесённым, пока не сошлось с эталоном:

```
python tools/judge/compare.py
```

Сверяются `whole`, `part` и значение — по дробям, не по float.
Судья обязан **проваливать** намеренно испорченную версию; это проверяется
отдельно, иначе зелёный результат ничего не значит.
