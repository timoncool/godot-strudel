# Судья: чем доказывается, что это тот же Strudel

Здесь лежит всё, чем плагин сверяется с оригиналом. Ничего из этого не входит
в поставку — `addons/strudel` самодостаточен.

## Что зафиксировано в репозитории

| файл | что это |
|---|---|
| `corpus.json` | 116 выражений Strudel, покрывающих язык |
| `effects.json` | 19 замеров звука по узлам цепи эффектов |
| `golden/haps.json` | ЭТАЛОН событий корпуса, снятый с живой Булки |
| `golden/track_haps.json` | ЭТАЛОН событий целого трека (2449 штук) |

Эталоны звука (`golden/fx_*.wav`) в репозиторий не кладутся — они весят
десятки мегабайт и пересниимаются командой ниже.

## Прогон

```bash
# события: корпус и целый трек
godot --headless --path . --script res://tools/judge/run_corpus.gd
python tools/judge/compare.py

godot --headless --path . --script res://tools/judge/run_track.gd
python tools/judge/compare.py --track

# звук: каждый узел цепи по отдельности (нужны эталоны, см. ниже)
bash tools/judge/check_effects.sh
```

## Как снимался эталон

Эталон берётся из **живой Булки**, а не из головы и не из вторых рук.

1. Открыть Булку (`bulka.app` либо десктопное приложение — оно раздаёт сайт
   на `127.0.0.1:4188`).
2. Поднять приёмник: `python tools/judge/receiver.py 4199`.
3. В консоли страницы выполнить снятие: страница забирает `corpus.json` или
   `effects.json` у приёмника, прогоняет их через `queryArc` (события) либо
   `renderPatternAudio` (звук) и отправляет результат обратно приёмнику.

Для звука перехватывается скачивание: `URL.createObjectURL` подменяется так,
чтобы блоб ушёл приёмнику, а не в папку загрузок.

🔴 **Числа сравниваются битами IEEE754, а не десятичной записью.** `String.num`
у Godot на восемнадцати знаках ошибается в последнем разряде — сверка краснела
бы на верных значениях.

## Проверка самого судьи

Зелёный результат ничего не значит, пока не доказано, что судья умеет краснеть.
Проверено мутациями:

| поломка | сколько проверок покраснело |
|---|---|
| арифметический сдвиг в RNG заменён логическим | 4 |
| `floor` у отрицательных отбрасывает дробную часть | 3 |
| разбор чисел без последовательностей Фарея | 2 |
| умножение дробей без сокращения крест-накрест | 2 |

Ни одна поломка не прошла незамеченной.
